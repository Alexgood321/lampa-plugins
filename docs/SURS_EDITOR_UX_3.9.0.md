# SURS Pro 3.9.0 — редактор полок

## Изменения

- iPhone: полноэкранный редактор по доступной высоте WebView, закреплённые заголовок и нижняя панель, отдельная прокрутка списка.
- iPad: центрированное окно шириной до 820px, высота до 88vh; Split View до 700px переключается на компактную компоновку.
- Mac/браузер: ширина до 960px, кнопки сортировки, поиск клавиатурой, перетаскивание мышью.
- Android TV: сохранены Lampa Modal/Controller и D-pad, контрастная индикация фокуса, поиск через клавиатуру Lampa.
- Типографика: заголовок 21/20px, имя полки 15px, описание 12px, сенсорные области не менее 44px.
- Вкладки «Активные/Скрытые/Все», меню категорий для мобильных, встроенный поиск по названию и источнику.
- Touch drag: удержание 220 мс, отмена на touchcancel, автопрокрутка.
- iPhone: внизу только «Добавить» и «Применить»; сброс, обнаружение источников и скрытие сторонних полок вынесены в верхнее меню.
- Предупреждение при выходе с несохранёнными изменениями; неизменённые настройки не сохраняются повторно.
- Данные и конфигурация 23 заводских полок (11 включены) сохраняются без миграции.

## Функциональные сценарии

1. Без изменений основная кнопка визуально неактивна и настройки не перезаписываются.
2. Скрытая полка перемещается из «Активные» в «Скрытые», фокус переходит к ближайшей видимой.
3. Изменить порядок/включить полку, применить и перезапустить: настройки сохраняются.
4. Найти полку по названию/источнику, очистить поиск: список фильтруется без потери поля ввода.
5. Перетаскивание только после удержания, отмена при срыве.
6. Меню дополнительных действий на iPhone: обновление, сброс и массовое скрытие внешних.
7. Выход с изменениями: сохранить, отбросить или продолжить.
8. Сброс отображает 23 заводские полки (11 активны).
9. Trakt/HDRezka, карточки с годом, кнопки SURS и внешние полки работают как прежде.

Автоматические smoke-тесты проверяют JS/настройки/селекторы. Поведение реальных WebView/Safari/Android TV требует аппаратной проверки.
